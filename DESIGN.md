# Интерфейс KaloDeal

| Область | Правило и источник |
| --- | --- |
| Палитра | Используйте семантические классы Tailwind v4 из `src/app/globals.css`. Светлый background — oklch(0.984 0.003 248), белые card/popover, foreground — oklch(0.145 0 0). Primary, secondary и ring синие, oklch(0.546 0.215 263). Accent лаймовый, oklch(0.849 0.207 129). Destructive красный, muted-foreground для пояснений, border/input для границ. У поверхностей есть парные foreground-токены. Там же заданы значения для .dark, sidebar и chart-1…5. |
| Шрифт и геометрия | Geist Sans из `src/shared/ui/site-document.tsx` используется для sans, heading и mono. Базовый радиус 0.625rem. Container центрирован с px-4. Карточки rounded-xl, отделены рамкой, ring или лёгкой тенью. Образец регистрации — `src/app/(auth)/register/page.tsx` с h1 от text-3xl до md:text-5xl, заголовком формы text-2xl и пояснениями text-sm. |
| Навигация и адаптивность | Общие шапка, main и подвал в SiteDocument. На узком экране секции регистрации идут в один столбец, с lg — в два. Навигация и меню — `src/widgets/public-header`, sidebar — `src/components/ui/sidebar.tsx`, JS-граница mobile 768 px — `src/hooks/use-mobile.ts`. Сохраняйте перенос длинного текста, доступность меню с клавиатуры и место под действия на узком экране. |
| Компоненты | shadcn base-nova, Base UI, Lucide и cn заданы в `components.json` и `src/components/ui`. Выбирайте существующие Button, Input, Select, Tabs, Sheet, AlertDialog, Badge, Card. У Button есть default, outline, secondary, ghost, destructive, link, размеры и focus-visible ring. Для ссылки с видом кнопки используется render с Link и nativeButton=false. |
| Формы | Образцы — `src/features/auth/components/register-form.tsx`, `src/features/create-listing/use-listing-form.ts`. React Hook Form + Zod, Field/FieldGroup, связанная метка, aria-invalid, FieldError с role=alert. При ожидании блокируется отправка, данные сохраняются при ошибке. Состояние успеха следует за результатом мутации. Общие уведомления toast.add и Toaster см. `src/components/ui/toast.tsx`. |
| Загрузка и ошибки | Suspense с каркасом конкретной формы или списка. `src/shared/ui/loading-status.tsx` даёт role=status и скрытую подпись. Образцы в `src/features/auth/components/auth-form-skeleton.tsx`, `src/entities/listing/ui/listing-skeleton.tsx`. Экранные ошибки и повтор загрузки — `src/app/error.tsx`, локальные error.tsx и not-found.tsx. Ошибки отправки выводятся около поля, через toast или role=alert как в `src/features/billing/billing-button.tsx`. |
| Пустые состояния | Сохраняйте заголовок раздела, называйте отсутствующие данные и показывайте доступное действие по контексту. Сверяйте с кабинетом объявлений и избранным в `src/app/(protected)/(user)/account`, выдачей `src/app/(localized)/[locale]/_ui/home-listings.tsx` и очередями `src/features/moderation`. |
| Статусы | `src/entities/listing/lifecycle.ts` задаёт подписи и переходы. `src/features/account/listing-status-badge.tsx` объединяет иконку и текст. PENDING и CHANGES_REQUESTED используют chart-4, ACTIVE — primary, HIDDEN и INACTIVE — muted с пунктиром, REJECTED — destructive, SOLD — accent. Причину решения и ограничение тарифа выводит MyListingRow отдельно от статуса. |
| Локали | /, /categories и /listings/[id] поддерживают EN и EL. Префикс /el для греческой версии, английский по умолчанию. Настройки в `src/i18n/routing.ts`, тексты в `src/i18n/messages`. Закрытые страницы и auth-формы преимущественно на английском. |
