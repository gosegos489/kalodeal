## Наблюдения по коду

- Вход и регистрация делегируют запросы Better Auth. У пользователя хранятся роль, accountType и отдельные поля модерации. Проверка чувствительных операций читает актуальную сессию. Подтверждение и сброс используют разные шаблоны Resend.
- Создание объявления выполняется через POST, очередь читает БД, публичная выдача учитывает статус, доступ по плану и состояние продавца. Для поиска используется серверный компонент, в /api/listings экспортирован POST. Параметр page доходит из browse-context в getListingSearchResults, затем в общий getPagination и SQL. Размер страницы задаёт вызывающий код.
- Контактные обращения, отчёты о чате, тексты документов и иконки категорий имеют отдельные рабочие процессы. Dashboard модератора не заменяет проверку каждого из них.
